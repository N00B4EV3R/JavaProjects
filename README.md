# JavaProjects

## ToyStore (Spring Boot)
A Java Spring Boot application simulating a toy store inventory system. It uses MVC architecture with Spring controllers, dependency injection (@Autowired), and connects to a MySQL database for data management. The project demonstrates structured backend design, RESTful endpoints, and CRUD operations.
### https://github.com/N00B4EV3R/toyStore

## ToyStore (JavaFX)
A Java desktop application built using the MVC architecture, featuring a clean separation between logic, data, and UI components. The project includes a Swing-based interface and integrates with a SQL database for data persistence. It demonstrates structured design patterns, event handling, and CRUD operations for efficient desktop app development.
### https://github.com/N00B4EV3R/java_desktop

## Inventory Manager (Console App)
A Java console application that manages product inventories through a simple text-based interface. It features robust exception handling and performs read/write operations on files using Java streams for efficient data storage and retrieval.
### https://github.com/N00B4EV3R/InventoryManager

## Student System Management (Console App)
A Java console application designed to manage student records efficiently. Built with a strong OOP structure, it uses Java streams for data manipulation and showcases clean, modular code organization.
### https://github.com/N00B4EV3R/javaStudentSystemManagement
